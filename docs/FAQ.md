# FAQ

**Do I need an account?** No. There are no accounts anywhere in QuickDrop.

**How long do Drops last?** 5, 10, 15 or 30 minutes. The server enforces the timer, not your device clock.

**Who can open my Drop?** Anyone with the code can view it. Only the creator can manage or delete it. Add a password for extra protection.

**What is burn after download?** The Drop is deleted as soon as it has been downloaded.

**What is the largest file?** 250 MB per file, up to 10 files per Drop.

**Is it end-to-end encrypted?** Not yet. It is on the roadmap.

**What do you collect?** Anonymous usage counts only. No cookies, no third-party trackers and no stored IP addresses. See the privacy section of the README.

**Is it free?** Yes. Donations are optional and run on free-tier infrastructure, so very busy periods can slow things down.
